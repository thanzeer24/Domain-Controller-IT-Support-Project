##  Ticket 3: Software Installation with Remote Support


---


HR user needed to install Notepad++ but did not have admin access and raised a ticket in Jira for admin access. IT assigned the ticket to himself and shared a TeamViewer session link via email. IT connected to HR computer via TeamViewer, entered admin username and password , and installed Notepad++. HR opened Notepad++ and verified it works. Ticket was then closed as resolved
