## 6. Scenario 2: Folder Access Request


---


HR user Pooja Saxena got promoted to Senior HR and raised a ticket in Jira to get access to the HR Confidential folder. IT user assigned the ticket to himself, went to Domain Controller, opened HR Confidential folder permissions, and added Pooja Saxena with Modify access. IT replied in Jira that permission has been changed. HR logged out and logged back in and was able to access the HR Confidential folder successfully. Ticket was then closed as resolved.
